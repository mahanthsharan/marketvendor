HOW TO GET STARTED:
═════════════════════════════════════════════════════════════════════

OPTION 1: Quick Start (Recommended)
  1. Read: QUICKSTART.md
  2. Install: python -m venv venv && pip install -r requirements.txt
  3. Initialize: python init_db.py
  4. Run Backend: python -m uvicorn main:app --reload
  5. Run Frontends: npm install && npm run dev (in each portal directory)

OPTION 2: Verify First
  1. Run: python verify_setup.py
  2. Check all prerequisites
  3. Then follow Option 1

OPTION 3: Run Tests
  1. Start backend first
  2. Run: python test_marketplace.py
  3. Automated tests verify all features
